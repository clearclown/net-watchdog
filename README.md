# net-watchdog

macOS 用の回線監視スクリプトです。インターネットへの疎通が途切れたら、Wi-Fi の MAC アドレスを変えて Wi-Fi を入れ直し、自動で復旧させます。

集合住宅などの CGNAT 回線で、Wi-Fi にはつながっているのに外へ出られなくなる現象への対策として作りました。

## 動作

1. 20 秒ごとに `8.8.8.8` へ ping し、失敗したら `1.1.1.1` も試します。
2. 3 回連続で両方に失敗すると復旧処理に入ります。
3. Wi-Fi の MAC アドレスをランダムなローカル管理アドレス（`02:xx:xx:xx:xx:xx`）に変えます。
4. Wi-Fi を切って 3 秒後に入れ直し、15 秒待って疎通を確かめます。
5. 結果を `/var/log/net-watchdog.log` に記録します。

MAC アドレスの変更は再起動すると元に戻ります。

## インストール

```sh
sudo ./install.sh
```

root の LaunchDaemon（`com.net.watchdog`）として登録され、起動時に自動で動き始めます。更新するときも同じコマンドです。

## アンインストール

```sh
sudo ./uninstall.sh
```

## 設定

| 環境変数 | 既定値 | 内容 |
| --- | --- | --- |
| `NET_WATCHDOG_IFACE` | `en0` | 監視する Wi-Fi インターフェース |
| `NET_WATCHDOG_LOG` | `/var/log/net-watchdog.log` | ログの出力先 |

確認の間隔と失敗回数のしきい値は、スクリプト冒頭の `CHECK_INTERVAL` と `FAIL_THRESHOLD` で変えられます。

## 注意

- MAC アドレスの変更には root 権限が必要です。
- 復旧処理のあいだ、Wi-Fi は 20 秒ほど切れます。
- ルーターや上流の機器そのものが落ちている場合は復旧できません。その間は約 80 秒ごとに Wi-Fi の入れ直しを繰り返します。
